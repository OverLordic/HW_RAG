# Доказательный RAG по ТФКП

Цель - выбрать все правильные варианты ответа, кратко обосновать их вырезками из учебника и указать исходные `block_id`. Если данных недостаточно, нужен отказ. Используется только известный PDF-учебник; генерация - Qwen3.5-4B без дообучения. Индекс строится без вызовов LLM. Система представляет собой фиксированную цепочку, агента и адаптивного цикла нет.

## Корпус и формулы

PyMuPDF извлекает текст 147 страниц с `sort=False`. Кириллица восстанавливается перекодированием latin1/cp1251 только для распознанных шрифтов. Математические знаки разбираются с учётом шрифта. Простые дроби восстанавливаются по положению символов относительно дробной черты, индексы внутри них - по размеру шрифта и базовой линии. Неоднозначные группы не исправляются предположениями.

Чанкинг учитывает страницы, заголовки и начала определений/теорем, целевой размер - 1800 символов. Получено 452 блока: медиана 429, максимум 3705 символов. Все исходные ID, страницы и разделы сохранены. Остались 988 меток неизвестных знаков в 99 блоках.

## Поиск, контекст и ответ

BM25 использует частоты слов без стемминга, `k1=1.5`, `b=0.75`:

$$S(d,q)=\sum_{t\in q}\log\left(1+\frac{N-n_t+0.5}{n_t+0.5}\right)\frac{f_{t,d}(k_1+1)}{f_{t,d}+k_1(1-b+b|d|/\overline{|d|})}.$$

В итоговом варианте добавлен `intfloat/multilingual-e5-small`: 117,7 млн параметров, CPU, 384 координаты, префиксы `query:`/`passage:`, усреднение выходов с маской и L2-нормировка. Ревизии E5 и Qwen зафиксированы в конфигурации. E5 видит первые 512 токенов: 78 из 452 блоков обрезаются, поэтому длинные фрагменты могут представляться неполно.

Из BM25 и E5 берутся по 20 кандидатов. Для объединения используется
$RRF(d)=\sum_j1/(60+rank_j(d))$. Первые три BM25 сохраняются, два оставшихся места заполняются по RRF без повторов. Это уменьшает риск вытеснения точных терминов семантически похожим текстом.

Второй компонент добавляет продолжение теоремы/леммы/следствия на следующей странице: раздел совпадает, продолжение начинается со строчной буквы и не открывает новую формулировку. Если начало потерялось при объединении, допускается добавить начало и продолжение вместе из BM25 top-5.

Контекст состоит из целых блоков с исходными ID, ограничен 12000 символами, десятью блоками и 4096 входными токенами вместе с вопросом и чат-шаблоном. При переполнении блоки удаляются целиком, связанная добавленная пара - вместе. Один вызов Qwen возвращает JSON: варианты, отказ, обоснование до 1200 символов и не более четырёх ссылок. Проверяются формат, принадлежность ссылок контексту и бюджеты; ошибочные математические ответы не исправляются по эталону. Веса и токенизаторы готовятся заранее, при предсказании разрешён только LLM endpoint.

## Эксперимент

Заключительный запуск `62bd9e01dd9d`: одни и те же 15 вопросов, корпус и параметры для всех пяти вариантов. Qwen работает в float16 без квантизации, `thinking=false`, greedy, `temperature=0`, `max_tokens=512`, тайм-аут 180 с. Расход каждого подтверждён журналом endpoint; максимум входа - 3993, выхода - 361 токен. 

| Вариант | Точные ответы | Q | Средняя C | Валидный формат |
|---|---:|---:|---:|---:|
| Без контекста | 8/15 | - | 1416,07 | 14/15 |
| BM25 | 11/15 | 0,64208 | 3541,87 | 14/15 |
| BM25 + E5 + продолжения | 11/15 | **0,69375** | 3557,47 | **15/15** |
| Без E5 | 11/15 | 0,64208 | 3530,40 | 14/15 |

Полные токены и медианы задержки находятся в `experiments.csv`; у итоговой системы медиана 12091 мс. До содержательной проверки Q у BM25 и «без E5» был 0,68875: q_001 обнулён за противоречие гипотезе о существовании частных производных. Неудачная первая фраза q_003 у гибрида принята как редакционная ошибка, поскольку дальнейшие условие и контрпример верны.

Выбран целый вариант BM25 + E5 + продолжения: лучший локальный Q, полный формат, стоимость на 0,44% выше BM25. Ответы разных вариантов не смешивались. Без E5 Q ниже на 0,05167. Без продолжений - на 0,04; расширение сработало только на q_006, где вариант без него также выдал невалидный JSON.

Прежний выбранный BM25 имел 10/15, Q=0,59458, C=3433,67.

## Три оставшиеся ошибки

1. **q_002, сопряжённые производные.** Найден `pdf_p012_b001`, но выбраны A,D вместо A,C. Объяснение путает производные по z и сопряжённому z. Причина: рассуждение и сопоставление формулы варианту; нужный фрагмент найден.
2. **q_007, интеграл от exp(z)/z³.** Процитирован `pdf_p028_b001`, но модель рассуждает о простом полюсе и вычете 1. На самом деле полюс третьего порядка, вычет 1/2, интеграл πi, вариант C. Выбран A. Причины: недостаточный источник, вычисление и несогласованность ID с текстом.
3. **q_015, радиус сходимости.** Процитирован `pdf_p099_b003` о продолжении; модель выбрала R=1. Голоморфность в единичном круге даёт лишь R≥1, без ближайшей особенности точный радиус неизвестен. Нужен отказ. Причины: нерелевантный поиск и необоснованное усиление вывода.

## Ресурсы и воспроизводимость

Kaggle, одна Tesla T4, доступно 14,56 GiB VRAM; E5 - CPU, четыре потока. JSON-индексы - 4705993 байта; вместе с подготовленными E5/токенизаторами - 512425904 байта. Наблюдаемый максимум RSS процесса/дочерних процессов - 9,67 GiB. Отдельное локальное измерение CPU-сборки - около 1,21 GiB.

Загрузка Qwen - 8,08 с после технического теста, первая загрузка - 64,41 с. Предельная искусственная нагрузка 4096+512 токенов прошла за 40,74 с с пиком 11,353 GiB GPU. Клиент - Python 3.11.18, GPU-среда - 3.13.15; версии сохранены в runtime. Чистая установка Python 3.11 проверена на macOS и в Linux ARM64.

Подготовлены восемь новых вопросов, по два на категорию: Руше, Вейерштрасс, вычеты, главные части и ветви корня.
