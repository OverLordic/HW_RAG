# RAG по ТФКП
**Крахмалев Алексей, группа М05-607в.**

Окончательная система: BM25 + multilingual-e5-small + продолжения формулировок, один вызов Qwen3.5-4B. 
На 15 открытых вопросах: 11/15 точных ответов, локальный Q=0.694, корректный формат имеют 15/15.
Пять экспериментов и две абляции описаны в report.md, полные метрики - в experiments.csv.

## Подготовка

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python extract_corpus.py
python build_index.py --corpus data/corpus.jsonl --output index --config config.json
```

Обязательные build_index/predict принимают пути из терминала относительно
текущей папки. Выходной каталог индекса может быть любым новым каталогом.

Все скачивания выполняются при подготовке. При предсказании E5 и токенизатор
читаются локально; сеть используется только для заданного LLM endpoint.
E5: `intfloat/multilingual-e5-small`, 117653760 параметров, CPU, четыре потока,
384 координаты, максимум 512 токенов, префиксы query:/passage:, усреднение
с маской и L2-нормировка. Ревизия:
`614241f622f53c4eeff9890bdc4f31cfecc418b3`.

## Предсказание

Задайте `LLM_BASE_URL` (с `/v1`, если нужно), `LLM_MODEL`, `LLM_API_KEY` и
`SUBMISSION_ID` в окружении терминала. Каждый запрос передаёт `X-Question-ID` и `X-Submission-ID`.

```bash
python predict.py --index ./index --questions ./dev_questions.jsonl --output ./answers_new.jsonl --trace ./trace_new.jsonl --config ./config.json
```

Цепочка: вопрос → BM25 и E5 → целые исходные блоки → один вызов Qwen → проверка
JSON. Параметры BM25: k1=1.5, b=0.75. Из 20 кандидатов каждого поиска первые три
BM25 сохраняются, остальные два места заполняются по RRF с константой 60.
Допускаются максимум два добавленных блока продолжения на следующей странице,
при совпадающем разделе и отсутствии новой формулировки. Потерянное начало
может добавляться вместе с продолжением из BM25 top-5.

Qwen: `Qwen/Qwen3.5-4B`, ревизия
`851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`, float16, без квантизации,
thinking=false, greedy, temperature=0, max_tokens=512, timeout=180 с.
Контекст ограничен 12000 символами, десятью блоками и 4096 входными токенами
вместе с вопросом и чат-шаблоном. При переполнении удаляются целые блоки;
связанная добавленная пара удаляется вместе. Input+512≤8192. Повторных
вызовов, агента и адаптивного цикла нет.

Ответ: id, answer_ids, abstain, rationale≤1200 символов, ≤4 citations.
При отказе оба списка пусты. Убираются только одинаковые ID и ссылки явного
отказа с пустым answer_ids; изменения и сырой ответ сохраняются. Ответы по
эталонам не исправляются. Ошибка формата даёт trace.valid=false и код 1,
расход ошибочного ответа всё равно учитывается. 

## Эксперименты

```bash
python run_experiments.py --index ./index --output ./outputs/another_run
python run_experiments.py --summarize --output ./outputs/another_run
```

Каталог должен быть пустым. Создаются уникальный run_id, исходный
source_bundle.zip и manifest.json с хэшами. Все варианты получают одинаковые
вопросы и параметры LLM:

| Имя | Компоненты |
|---|---|
| model_only | Без контекста. |
| baseline | Один BM25 без расширения. |
| candidate | BM25 + E5 + продолжения, итоговый вариант. |
| no_dense | BM25 и продолжения, E5 отключён. |
| no_context_extension | BM25 + E5, продолжения отключены. |

В каждом подкаталоге - config/answers/trace. В каталоге запуска - журнал API,
manifest, runtime, CSV и scores. Неуспешный вариант сохраняется с кодом 1. Новая содержательная проверка должна иметь `_hashes`, равное `review_basis` manifest.

Q - среднее четырёх средних по категориям; точность требует полного набора
вариантов. F1 ссылок берётся по лучшему citation_set. Невалидный вопрос остаётся
в знаменателе с нулём. Существенное противоречие в обосновании также даёт ноль.
Стоимость - input+4×output+256×calls.

## Проверки и ограничения

```bash
python -m pip check
```

Дроби восстанавливаются только при однозначном расположении символов; вложенные формулы, сложные пределы и неизвестные шрифтовые знаки остаются ограничением. Qwen по-прежнему ошибается в формулах Виртингера, вычетах, теореме единственности и точном радиусе сходимости.
